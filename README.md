# 📚 LibSync (Library Management System)

LibSync is a console-based library automation system developed in C# using Object-Oriented Programming (OOP) principles. This project was designed from scratch to enhance foundational data structures, layered architecture logic, and file management skills.

## 🚀 Features

* **Book Management:** Add new books to the system (with Name, Writer, Category, and Stock details).
* **Loan & Return System:** Search for existing books in the library, borrow them to decrease stock, or return them to increase stock.
* **Comprehensive Listing:** Display detailed information for all books registered in the library.
* **Error Handling & Loop:** User guidance against incorrect keystrokes and an uninterrupted menu loop.

## 🛠️ Technologies Used

* **Language:** C# (.NET Core / .NET Framework)
* **Concepts:** Object-Oriented Programming (OOP), Collections (`List<T>`), Control Flow Statements (`while`, `foreach`, `if-else`).
